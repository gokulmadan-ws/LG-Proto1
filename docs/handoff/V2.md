## Routes and query parameters

`#/opportunities?type=overCap|nearCap|renewal|uplift&status=open|reviewed|all&q=<text>&sort=value|date|type&flag=<flagId>`

- Every filter lives in the address, so links, Back, reload and Share keep it. Invalid values fall back to the defaults (type none, status open, sort value). `q` is debounced (250 ms) into the address; the box itself filters instantly.
- Status: Open = To investigate and Under review; Reviewed = Explained and No action; All = both. Chip counts follow search and status but not the type, so a chip tells you what you would get.
- Sort: Highest value first (the engine's rank), Soonest action date (rows with no action date last), Type (over cap, close to cap, renewal, price increase). Ties always fall back to the overall rank. Rank numbers shown are the overall ranks, so they stay the same under any filter or sort.
- `?flag=<id>` works on any route: `#/renewals?flag=F-C-005-overCap`, `#/overview?flag=...`. Closing removes only that parameter (replace, Back is not polluted). An unknown id opens nothing.
- Other pages open the drawer with `setQuery({ flag: id })` (flag ids are in `estate.ranked`, `estate.watch`, `estate.radar.groups.*.items[].flagId`, `estate.derived[cid].flagIds`).

## Behaviour worth knowing

- Totals bar (R27): "Showing 19 opportunities, £6,145,238 indicative" is summed from the visible rows that count (`isCounted`). A second line splits the same sum by basis ("£4,427,260 already paid · £642,478 projected at the current pace · £1,075,500 per year") so the mixed units are never one unlabelled number. Reviewed rows in view are listed as "1 reviewed, £3,350,000 not counted."; under Open a note says "1 reviewed opportunity is hidden." with a "Show reviewed" link.
- Export (R29): the rows you can see, in the order shown (19 by default), as `kontor-opportunities-2026-10-06.csv`, UTF-8 with BOM, CRLF. Columns: Rank, Type, Contract id, Contract, Supplier, Indicative GBP, Basis, Reason, Action by, Confidence, Status, Page, Clause, Data, As at. "Data" is "Sample data, as at 2026-10-06" on every row and "As at" repeats the date. Failure shows the copy-deck error as an error toast (`COPY.errors.export`, split into title and description). An empty view shows a warning toast instead of a header-only file.
- Triage (R61): the select is in the drawer's sticky footer beside the one primary button (the evidence ClauseLink). It persists through `actions.setTriage`, the totals bar, chips, Overview and everything else recompute live, and a toast says "<Contract>: marked Explained. The headline is now £2.8m." (`triageToast`, with the headline computed by `computeEstate` so it names the NEW figure). The drawer stays open when the row leaves the Open list. Closing it when the row has gone moves focus to the page's status line (`data-opp-fallback`) instead of `<main>`.
- Drawer contents: contract and supplier, flag type pill (reviewed = grey), confidence pill, indicative value with basis, the notice date or next price review with relative text, the short caveat, "Why this is flagged" (`reasonFor`), "How this is calculated" (one rule sentence, then the numbered `flag.breakdown`; the last line is the row amount to the pound, checked for all 19 flags and both watch flags), "Confidence" (`confidenceReason`), "Where it comes from" (every clause the flag relies on with clause, page of N, quote, plus the illustrative-text label), "Reasons this may not be a saving" (`src/data/reasons.js`), "Open contract". The method link goes to `cap` (over cap, close to cap), `indicative` (renewal) or `uplift`; a second link goes to `confidence`.
- The evidence link keeps the page it came from: opened on `#/renewals` it is `...?from=renewals`; on a route that is not a rail item it falls back to `opportunities`.

My axe runs cover every state except that one; the e2e prints a `skip` line for it and fails on anything else.

- At 1366x768 the first row is fully visible and the second is cut; at 1440x900 two rows fit. Rows are 99px tall (A3's `OpportunityList`).
- The longest reasons are cut to two lines in the row (A3's clamp); the drawer has the full sentence.
- Hand-checked on screen against requirements 6.6: ranking, amounts, counts, totals, the two watch rows (89.1% of the cap, 90.8% of the contract value), the F-C-005 and F-C-004 breakdowns. Not checked: any number on a page this agent does not own.
