## Judgement calls worth knowing

- **Caveat on the Overview is the short form** (`COPY.caveat.short`, generic, no Sefton figure, per decision 7 and the density rule). The long form sits on Opportunities (V2). R14's "exact caveat in 7.2" is therefore met by the short form plus the link.
- **Radar page uses full pounds** (`format={gbpFull}`): R31 reads `£6,930,000 a year`. The Overview strip uses `fmtGBPCompact` (`£6.9m a year`, R18). I widen the deadline and value columns above 920px and the value column in the stacked layout so the longer strings do not wrap (`Renewals.css`).
- **Attention rows are a separate list, not lane rows**, as the blueprint brief says ("group first, then RadarLanes for the three bands"). They are fed from `estate.radar.attention` (order C-001, C-016, C-007). Their text is `needsAttentionText` only, as the R34 AC reads. The `actionLine` for C-001 (extension date passed, agree in writing or re-procure) is therefore not shown; say so if you want it as a second line.
- **Auto-renews** on the bands is the library's own marker restyled as a neutral pill in `Renewals.css` (`.rn .kviz-rl__auto`, same tokens as the kit `Pill`); in the attention list it is the kit `Pill`.
- **Total contract value per band** (R31 mentions it) is only in the "Show table" twin; `RadarLanes` shows the annual value.
- **No `ChartFigure` on the radar.** `ChartFigure` renders a `<header>` and `tests/smoke.mjs` ("shell landmarks") counts every `header` under `#root` and expects exactly the shell's one, so any page with a ChartFigure fails it. A header inside a figure is not a banner landmark, so the test is too loose, not the page wrong. `LanesFigure` in `Renewals.jsx` is the same markup and classes with a `div` head (legend, "Show table" twin through the charts `ChartTable`, footnote as `figcaption`). The Overview evidence cards likewise use `div`s, not `header` and `footer`. Request below.
