## Router (`src/lib/router.js`)

```js
const { name, seg, parts, query, path, hash } = useRoute();
// '#/opportunities?type=overCap'                  name 'opportunities', seg [],                      query.get('type') 'overCap'
// '#/spend/matches'                               name 'spend',         seg ['matches']
// '#/contracts/C-005'                             name 'contracts',     seg ['C-005']
// '#/source/C-005/X-C-005-maximumValue?from=renewals'   seg ['C-005', 'X-C-005-maximumValue']
// '', '#', '#/'                                   name 'overview'
```
`seg` is the segments AFTER the name (same shape as `hrefFor`); `parts` = `[name, ...seg]`; `path` = `'/spend/matches'` (no query).
```js
navigate('#/spend/matches' | '/spend/matches', { replace: false })
setQuery({ flag: id })            // merge into the current route's query; null, undefined, '' or false removes; replace by default
setQuery({ flag: null })
hrefFor('source', { seg: [contractId, extractionId], query: { from: 'opportunities' } })   // '#/source/C-005/X-...?from=opportunities'
usePageTitle(contract.title)      // overrides the default `<Page> | Kontor financial layer`; cleared on the next route
```
Route change = the PATH changed. Then: `document.title`, `#shell-main` scroll reset to 0, focus moves to the page `<h1>` one frame later (not on first load, not on query-only changes, so filters, `?flag=` and `?s=` never jump). A view's own `scrollIntoView` (Method `?s=`) runs after the reset. Unknown name, too many segments (`#/overview/x`) or an invalid Spend tab render `NotFound` with a not-found title and no rail highlight.

`routes.js`: `ROUTES[name] = { title, rail, component, maxSeg }`, `resolveRoute(route)`, `RAIL`. Components get `route` plus: `Contracts`/`ContractDetail` (`id`, `contractId`), `Source` (`contractId`, `extractionId`, `from`), `Spend` (`tab`: `'cap' | 'matches' | 'no-contract'`). Source keeps the rail item of `?from=` (default Opportunities); Method and Evidence highlight nothing.

## UI context (`src/lib/ui-context.jsx`)

```js
const ui = useUI();   // stable functions; outside a provider it degrades to no-ops (one console.warn), it does not throw
ui.toast({ tone: 'info' | 'success' | 'warning' | 'error', title, description })   // or ui.toast('text'); errors stay and use role="alert"
ui.openAbout(el?)  ui.openFeedback(el?)  ui.openSettings(el?)  ui.openDemoGuide(el?)  ui.openMenu(anchorEl)   // el = element to return focus to (default: the focused one)
ui.closeAbout() closeFeedback() closeSettings() closeDemoGuide() closeMenu() dismissToast(id)
const ok = await ui.confirm({ title, description, confirmLabel: 'Reset changes', destructive: true });       // Cancel is focused first
const s = useUIState();   // { toasts, about, feedback, settings, demoGuide, menu: { open, anchor }, confirmRequest }
```
Overlays are mounted once by `components/Overlays.jsx` with props `{ open, onClose }` (`MenuPopover`: `{ open, anchor, onClose }`; `FlagDrawer`: none, reads `?flag=`). Focus returns to the opener on close unless the route changed meanwhile; an overlay opened from the open Menu returns focus to the Menu button.

## Global CSS decisions (`styles/app.css`, `shell.css`)

One global focus rule: 2px accent outline, lowest specificity so a component can draw its own; `!important` only for elements with an inline `outline: none` (DS Button, Input, Textarea, Select). Dark `--focus-ring` fixed (DS defined it grey). Per-theme `color-scheme`. No body background outside `shell.css`. The blob texture is referenced once (`shell.css`) and stays a file (`../assets/blob-texture.png` next to `dist/`), not 465 KB of base64; `make-standalone` inlines it.

## Traps worth knowing

1. **`design-system/_ds_bundle.js` mounts its own demo app into `#root`** (last lines, inside a try/catch). `index.html` therefore loads React, ReactDOM and the DS bundle BEFORE `<div id="root">`, so the demo throws on a null container and the components still register. Do not move `#root` above those scripts: the DS demo UI would flash up first. `window.Springboard20DesignSystem_019e02.__errors` holds that one expected entry (`ui_kits/springboard/App.jsx`).
2. `scripts/ds-offline.mjs` writes `dist/ds/` atomically (temp file and rename), because several agents build at once. It drops `@font-face` rules whose TTF is not shipped (Inter 100/200/800/900, some italics) instead of letting them 404.
3. `build.mjs` fails if any CSS in `dist/`, `dist/ds/` or the outdir references `http(s)://` (comments and `www.w3.org` namespace URIs inside SVG data URIs are ignored).

## How to test

```
npm test                              # engine test, then smoke (builds src/main.jsx into .scratch/smoke first, never touches dist/)
node tests/smoke.mjs --only theme,axe # groups: routes theme offline keyboard shell router ui axe layout standalone
node tests/smoke.mjs --dist .scratch/<id>   # test another build
npm run standalone && node tests/smoke.mjs --standalone --dist dist --only standalone
```
`tests/lib/harness.mjs`: `launch({dist})`, `h.newPage({ theme: 'dark'|'light'|null, viewport, blockStorage, hangExternal, delay, dist })`, `visit(t, hash)`, `go(page, hash)`, `setTheme(page, theme)` (alias `theme`), `axe(page)`, `externalRequests(t)`, `firstContentfulPaint(page)`; `t.requests` and `t.errors` are the request log and console/page/HTTP errors. Smoke tests views generically (one h1, title suffix, rail, no overflow, axe) so it keeps working as stubs are replaced; the overlay checks accept any `dialog[open]` or `[role=dialog]`.

Measured: first contentful paint 232 ms with Google Fonts and cdnjs hanging; 0 requests outside the origin across all routes; axe 0 violations (wcag2a, wcag2aa, wcag21aa, wcag22aa, best-practice) on all 18 routes in dark and light, with About, Settings, Menu, a toast, the confirm dialog and the error panel open; no horizontal scroll at 1440x900, 1024x768, 390x844.
